# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be decent to each other. Assume good faith, critique code rather than
people, and accept that maintainers have limited time.

Report unacceptable behaviour by opening a private security advisory (which is
the only private channel this repository has) or by contacting a maintainer
directly. Reports are handled confidentially.
